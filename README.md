# Console Load Testing

Консольное приложение для нагрузочного тестирования веб-сайтов с поддержкой сценариев тестирования.

## Возможности

- **Множественные URL**: Тестирование нескольких URL-адресов одновременно
- **Режимы работы**: Sequential (последовательный) или Random (случайный) выбор URL
- **Виртуальные пользователи**: Имитация одновременной работы нескольких пользователей
- **Сценарии тестирования**: Гибкая настройка нагрузки по времени с автоматической калибровкой
- **Заголовки запросов**: Поддержка кастомных HTTP заголовков
- **Статистика в реальном времени**: Отображение прогресса тестирования
- **Сохранение результатов**: Экспорт результатов в CSV формат
- **Анализ результатов**: Загрузка и анализ сохраненных результатов

## Установка

1. Убедитесь, что у вас установлен .NET 9.0 или выше
2. Склонируйте репозиторий
3. Соберите проект: `dotnet build`

## Использование

### Режимы работы

Приложение поддерживает несколько режимов работы:

#### 1. Режим аргументов командной строки

```bash
# Простой тест
app.exe --urls https://example.com --users 5 --requests 10

# С URL заголовками
app.exe --urls https://api.example.com --header "Authorization: Bearer token" --users 10 --requests 50

# Со сценариями (НОВОЕ!)
app.exe --urls https://example.com --scenarios "1:20:3,2:30:5"
```

#### 2. Режим конфигурационного файла

```bash
app.exe --config config.json
```

#### 3. Интерактивный режим

```bash
app.exe
```

#### 4. Режим анализа результатов

```bash
app.exe --load results1.csv results2.csv
```

## Сценарии тестирования

Сценарии позволяют создавать реалистичные профили нагрузки, где вы можете указать:
- Количество виртуальных пользователей
- Количество запросов на пользователя
- Длительность сценария в секундах

### Формат сценариев

Сценарии указываются в формате: `пользователи:запросы:секунды`

Примеры:
- `1:20:3` - 1 пользователь делает 20 запросов в течение 3 секунд
- `2:30:5` - 2 пользователя делают 30 запросов в течение 5 секунд
- `1:20:3,2:30:5` - сначала 1 пользователь (20 запросов за 3 сек), затем 2 пользователя (30 запросов за 5 сек)

### Калибровка

Перед запуском сценариев приложение автоматически выполняет калибровку:
1. Выполняет несколько тестовых запросов для определения среднего времени ответа
2. На основе этого рассчитывает задержки между запросами для равномерного распределения нагрузки

## Параметры командной строки

| Параметр | Короткий | Описание |
|----------|----------|----------|
| `--urls` | `-u` | URL-адреса для тестирования (можно несколько) |
| `--mode` | `-m` | Режим работы: `sequential` или `random` (по умолчанию: sequential) |
| `--users` | `-v` | Количество виртуальных пользователей (по умолчанию: 1) |
| `--requests` | `-r` | Количество запросов на пользователя (по умолчанию: 1) |
| `--delay` | `-d` | Задержка между запросами в миллисекундах (по умолчанию: 0) |
| `--scenarios` | | Сценарии в формате `users:requests:duration,users:requests:duration` |
| `--header` | `-H` | Заголовки запроса в формате 'Name:Value' (можно несколько) |
| `--config` | `-c` | Путь к файлу конфигурации (JSON) |
| `--save` | `-s` | Путь для сохранения результатов в CSV файл |
| `--load` | `-l` | Пути к файлам результатов для анализа (можно несколько) |

## Конфигурационный файл

Пример конфигурации (`config.example.json`):

```json
{
    "Urls": ["https://example.com", "https://httpbin.org/get"],
    "UrlMode": "Sequential",
    "VirtualUsers": 80,
    "RequestCount": 100,
    "DelayMs": 0,
    "Scenarios": [
        {
            "VirtualUsers": 1,
            "RequestCount": 20,
            "DurationSeconds": 3
        },
        {
            "VirtualUsers": 2,
            "RequestCount": 30,
            "DurationSeconds": 5
        }
    ],
    "UseScenarios": false,
    "CalibrationRequests": 5,
    "ChartTimeStepSeconds": 1,
    "Headers": {
        "User-Agent": "LoadTest/1.0",
        "Accept": "application/json"
    }
}
```

## Примеры использования сценариев

### Пример 1: Постепенное увеличение нагрузки

```bash
app.exe --urls https://api.example.com --scenarios "1:10:2,5:50:10,10:100:15"
```

Этот сценарий:
1. Начинает с 1 пользователя, делающего 10 запросов за 2 секунды
2. Затем переходит к 5 пользователям, делающим 50 запросов за 10 секунд
3. Завершается 10 пользователями, делающими 100 запросов за 15 секунд

### Пример 2: Стабильная нагрузка

```bash
app.exe --urls https://api.example.com --scenarios "10:200:30"
```

10 пользователей выполняют 200 запросов в течение 30 секунд.

### Пример 3: Пиковая нагрузка

```bash
app.exe --urls https://api.example.com --scenarios "50:1000:60"
```

50 пользователей выполняют 1000 запросов в течение 60 секунд.

## Вывод результатов

Приложение предоставляет подробную статистику:

- **Успешные/Неуспешные запросы**: Диаграмма распределения
- **Время ответа**: Среднее и 95-й процентиль
- **Статусы HTTP**: Распределение по кодам ответа
- **Статистика по URL**: Детальная информация для каждого URL
- **Графики по времени**: RPS и ошибки в динамике
- **Сводные отчеты**: Анализ нескольких тестов

## Сохранение и анализ результатов

```bash
# Сохранение результатов
app.exe --urls https://example.com --users 10 --requests 50 --save results.csv

# Анализ сохраненных результатов
app.exe --load results1.csv results2.csv results3.csv
```

## Технические детали

- **Язык**: C# .NET 9.0
- **HTTP клиент**: HttpClient с поддержкой кастомных заголовков
- **Асинхронность**: Полностью асинхронная обработка запросов
- **Отмена**: Поддержка CancellationToken для корректного завершения
- **Потокобезопасность**: Thread-safe коллекции для результатов
